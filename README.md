One word an agent says when it has no idea what to do: **Buffering…buffering…**

Not thinking. Not fixing. Just a stall that loops forever — the honest sound
of a machine caught out mid-task with nowhere to go.

## Run

`main.py` (Python 3, no dependencies) writes the word to `/output/entry.txt`:

```sh
python3 main.py
```
